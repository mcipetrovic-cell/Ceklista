# Чек-листа — упутство за рад на програму

Посебан програм (Ceklista.exe) издвојен из Саве: чек-листа велике овере и сажетак изабраних података. Корисник је
јавни бележник (није програмер): одговори ћирилицом, кратко, прво резултат; упутства корак по корак.

## Правила
- **Један извор питања је Сава.** `ceklista/pitanja.py` је препис (scripts/preuzmi_iz_save.py) — не мења се руком.
  Правила у `logika.py` прате `sava_app/cek_lista.py` и `cek_lista_modul.py`; `tests/test_isto_kao_sava.py` пореди
  (SAVA_PUT). Ново правило које Сава нема — само уз изричит налог бележника, и записати у README.
- **Стварни подаци странака никад** (ни у пробама, ни у примерима): само измишљена лица (ПЕТАР ПЕТРОВИЋ, ЈЕЛЕНА
  ЈОВАНОВИЋ). Програм не тражи и не чува ЈМБГ. `.ceklista`, `.docx`, базе и HAR не иду у Git
  (scripts/provera_pre_izdanja.py).
- **Без мреже и без додатних библиотека** у програму (само стандардни Python). Нова зависност само уз дозволу.
- Правне одлуке не доноси програм: последице и КОНТРОЛА само набрајају; одлучује јавни бележник.
- Свака исправка има регресиону пробу; ниједна проба се не брише ни не слаби.
- Идентификатори латиницом без дијакритика, коментари и поруке ћирилицом.

## Издање
`VERZIJA_BROJ` у `ceklista/__init__.py` + ставка у CHANGELOG.md → push на main → GitHub Actions прави Ceklista.exe и
Releases (v<верзија>). Пре тога: `python -m pytest -q tests` (прозор под `xvfb-run`) и `python main.py --provera`.
