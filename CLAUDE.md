# Чек-листа (Ceklista.exe) — упутство за рад и пренос контекста

Овај фајл преноси контекст из разговора на claude.ai: рад на Чек-листи се 27.11.2026 преселио у посебан разговор.
Корисник је јавни бележник (није програмер). Одговарај ћирилицом, кратко, прво резултат; упутства корак по корак,
са тачним кликовима.

## Шта је програм
- **Порекло:** посебан програм издвојен из Саве (програм канцеларије, репо `mcipetrovic-cell/Sava`, FastAPI).
  Налог 26.11.2026: „из Саве извучемо модул Чек-листа… једна мала апликација… резултат сажети подаци који су
  изабрани“, „посебан програм који се даунлаудује у формату Ceklista.exe“.
- **Почетак (налог 27.11.2026):** програм почиње **графичким приказом чек-листе** — листом „Чек листа 23.1“
  канцеларије (PDF од 24.12.2022, ЧЕК ✈ 23.1), распоређеним као на папиру — и то је **једини улаз у чек-листу
  предмета**. „Што једноставније радимо.“
- **Сава остаје непромењена.** Њен модул Чек-листа и даље постоји у Сави.

## Како је направљено
- **Програм:**
  - Python, само стандардна библиотека (tkinter, json, zipfile).
  - Word `.docx` се прави без python-docx (`word.py`).
  - PyInstaller onefile → `Ceklista_<верзија>.exe` (`Ceklista.spec`, иконица `data/Ceklista.ico`, позадина
    `data/livada.png`).
- **Питања:**
  - `pitanja.py` је **препис из Саве** (`scripts/preuzmi_iz_save.py`) и не мења се руком.
  - Правила у `logika.py` прате `sava_app/cek_lista.py` и `cek_lista_modul.py`: применљивост (да / не / не зна
    се / чека), пет статуса, предлози (нису одговор), групна потврда виђеног списка, `provera`, `kontrola`,
    парафи.
  - `tests/test_isto_kao_sava.py` пореди препис и правила са Савом (SAVA_PUT; покреће се Python-ом Саве, коме
    треба lxml).
- **Лист 23.1** (`list23.py`):
  - Ставке које значе исто као питање Саве уписују се у то питање.
  - Ставке којих у Сави нема су нова питања у целини `L23` („Лист 23.1 — остале ставке“), без правила.
  - `logika.DEFINICIJA` = питања Саве + L23. КОНТРОЛА (спремно за читање) мора остати иста као у Сави.
  - Питање о исплати на листу гласи „купац“, као уредничка исправка у Сави.
- **Прозор:** `gui.py`.
  - Почетна страна је `LIST` (`_strana_lista`): кућице, линије, ћелије КОНТРОЛЕ, парафи.
  - Остале стране: странке, целине А–И, Л, L23, провера непокретности, парафи, сажетак.
  - `Ulaz` је списак започетих чек-листа.
  - Страна се поново исцртава само кад се промени изглед (`_potpis`). Тако поље у коме се куца и клик на друго
    питање не нестају.
  - `_sacuvaj_otvoreno` уписује сва започета поља (фокус на Windows-у није поуздан).

## Правила рада
- **Стварни подаци странака никад**, ни у пробама ни у примерима: само измишљена лица (ПЕТАР ПЕТРОВИЋ, ЈЕЛЕНА
  ЈОВАНОВИЋ). `.ceklista`, `.docx`, базе и HAR не иду у Git (`scripts/provera_pre_izdanja.py`).
- **Без мреже и без нових зависности** у програму, осим уз дозволу.
- Правне одлуке не доноси програм: последице и КОНТРОЛА само набрајају.
- Свака исправка има регресиону пробу. Проба се мења само кад бележник промени понашање, и то се запише.
- Идентификатори латиницом без дијакритика; коментари, поруке и документација ћирилицом.

## Провера и издање
- **Окружење у cloud сесији:**
  - `apt-get install -y python3-tk` (Python 3.12);
  - venv са `--system-site-packages`;
  - `pip install pytest pyinstaller` (и `pillow` само за снимке и `scripts/napravi_*`).
- **Пробе:** `xvfb-run -a python -m pytest -q tests` (90 проба, 2 прескочене). Затим `python main.py --provera`.
- **Издање:**
  1. Повећати `VERZIJA_BROJ` у `ceklista/__init__.py` и записати верзију у CHANGELOG.
  2. Push на `main` покреће `.github/workflows/izdanje.yml` (Windows): контрола, пробе, PyInstaller, самопровера
     `Ceklista.exe`, Releases `v<верзија>`.
  - Остале гране: `probe.yml`.
  - Конзола на Windows-у нема ћирилицу: зато PYTHONUTF8.
- **Издања:**
  - 1.0 (26.11.2026);
  - 1.1 (27.11.2026, лист 23.1);
  - 1.2 (27.11.2026, верзија у називу, унапред означено, без пореских пријава, наставак започете).
  - Линк: https://github.com/mcipetrovic-cell/Ceklista/releases
